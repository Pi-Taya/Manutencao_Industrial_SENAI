-----Instalando dependencias laravel no poweshell

composer install
(Nota: Se aparecer o erro dizendo que 'composer' também não é reconhecido, use o caminho completo ou baixe o composer.phar direto na pasta do projeto rodando estes dois comandos):
powershell
C:\xampp\php\php.exe -r "copy('https://getcomposer.org', 'composer-setup.php');"
C:\xampp\php\php.exe composer-setup.php
C:\xampp\php\php.exe composer.phar install


------Para abrir no testar o sistema

abrir o xampp de start no mysql e apache

no terminal do xamp atraves do shell entrando na pasta do projeto atraves dos comandos a seguir

Alternativa sem sair do terminal do VS Code: digite o caminho completo do PHP do XAMPP):
powershell
C:\xampp\php\php.exe artisan migrate
C:\xampp\php\php.exe artisan serve



------Abrir o sistema

cd C:\Users\Aluno\Downloads\Manutencao_Industrial_SENAI

php artisan migrate

php artisan optimize:clear

php artisan serve

O terminal vai exibir uma mensagem parecida com:
INFO  Server running on [http://127.0.0.1:8000].
(Mantenha essa janela do terminal aberta enquanto estiver testando; se fechar, o site sai do ar).
